# Third-party dependencies

ReadyBy's original source is separate from installed packages. Package distributions and their licence files are installed in the local virtual environment, which is excluded from source archives.

Direct dependencies:

- Official MCP Python SDK, version 2.3.0: MIT. https://github.com/modelcontextprotocol/python-sdk
- Google OR-Tools, version 9.15.6755: Apache-2.0. https://github.com/google/or-tools

Transitive dependencies are recorded in requirements-lock-win-py314.txt. No third-party logos, fonts, music, personal data or external visual assets are bundled. Before a public source release, preserve the notices required by any dependencies that are actually redistributed; this package only declares dependencies for installation from their registries.
